# pyfetch

A minimal fastfetch-style system info tool written in Python.

Prints your OS, kernel, shell, uptime, CPU, memory, disk, IP, and battery
next to a small ASCII logo — like `fastfetch`/`neofetch`, but simple and
easy to hack on.

## Install (from source)

```bash
git clone https://github.com/yourname/pyfetch
cd pyfetch
pip install .
```

## Run

```bash
pyfetch
```

## Install without cloning (once published to PyPI)

```bash
pip install pyfetch-izak
pyfetch
```

## Development

```bash
pip install -e .
```

The `-e` flag installs it in "editable" mode, so changes to the source
show up immediately without reinstalling.
